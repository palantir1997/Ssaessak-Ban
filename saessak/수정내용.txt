수정한 부분만 정리:
1) index.php의 병원소개 버튼 링크를 about.html → html/about.html 로 수정
2) includes/header.php의 병원소개/조직도 링크를 about.html → html/about.html 로 수정
3) html/about.html을 단독 실행 가능한 완성 HTML로 감쌈
   - 기존 about 본문 내용은 그대로 유지
   - 폰트 Pretendard, Tailwind 설정 유지
   - CSS 경로는 ../css/style.css 로 맞춤
4) 혹시 루트 about.html로 들어가도 html/about.html로 자동 이동하도록 about.html 리다이렉트 파일 추가

적용 방법:
- C:\xampp\htdocs\Ssaessak-Ban\saessak 안에 있는 같은 파일 위치에 덮어쓰기
- 주소: http://localhost/Ssaessak-Ban/saessak/index.php
- 병원 안내 버튼 누르면 http://localhost/Ssaessak-Ban/saessak/html/about.html 로 이동해야 함
